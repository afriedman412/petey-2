## What was built

- **Pipeline per form:** `scripts/run_form.sh <form> <blank rel>` -> `petey/validate/form_run.py`: fresh label ->
  page check of every field -> the loop (validate, rule fixes, reviewer, adjudicator), with an Opus check of the
  changed fields and their neighbours each round -> the `.bpt`, written once when the loop stops, to
  `runs/judge_eval/blueprints/<form>.bpt`. One record per run: `runs/judge_eval/form_runs/<form>.json` (round 0 in
  full, then each round's changes and new verdicts, `code` version and `config` with every model and setting;
  `form_run.state()` rebuilds any round).
- **Models:** labeler Gemini 3.8 Flash; page check Gemini 3.8 Flash at round 0 (each page as 3 strips: Gemini sees an
  image at ~1,100 tokens to Opus's ~4,800), Opus 5 in the loop; reviewer Opus 5; classifier, reader and
  adjudicator still Sonnet 4.6 (moving them to Gemini is parked in `docs/TODO.md`, Later).
- **Runs done, results on the laptop under `runs/judge_eval/`:**
  - old library sets 1-5 (about 25 forms; sets 1-3 on an earlier pipeline);
  - T1 (`runs/judge_eval/launch_t1.txt`): 89 / 89 blueprints, all stable; 13 ran locally, 76 on the GCP runner;

## The review page

`PYTHONPATH=. venv/bin/python -m petey.validate.blueprint_review` (port 5005).

- Picker: "launch T1" / "launch T2" sections, each form with the page check's errors and suggestions.
- Each field: one plain sentence per reason it is questioned (`witness.explain`). Checks are graded by how often
  the person agreed with them on 1,508 reviewed fields (`witness.grade`): errors contest a field, suggestions
  (option captions, grouping, not a field, checkbox rows) do not, hints (no better than chance) stay in the raw
  details. T1 contested fields: 3,148 -> 515.
- Corrections: field name, type, semantic type (registry name, or "none" to clear) and pattern (regex, or "none").
  Apply buttons in Review and Add / remove write them into the blueprint with a record (`x_petey_hand_edit`), as
  Groups already did.
- "review edits": sends the person's flags with notes to an agent (`petey/validate/flag_agent.py`, Opus 5), which
  proposes a correction per field ("Agent proposes" + "use"); nothing is written until apply. Tested only on
  92900-A; ACORD 126 has 36 waiting.
- Review records live on the data-only branch `review-records`; save with `scripts/save_review_records.sh`.
