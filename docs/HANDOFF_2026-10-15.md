## Built today

### Passes after generation

`scripts/validate_passes.sh <ids>`, on each form's working copy, every change recorded as Claude's (verdicts follow renames):

1. **Mechanical pass** (`eval/mechanical_pass.py`), plain code.
   - Fixes: group type, person_name, patterns, Yes / No pairs, row groups (`eval/cell_groups.py`), dropdowns.
   - Checks only: grid naming, uncovered boxes, inverted keys, code captions, far pages, bad semantic types, name-check errors and hints.
2. **Naming standard** (`eval/standardize_names.py --apply`, `--only REGEX`): adds `_pct` and `_days` / `_months` / `_years`.
3. **Re-read captions** (`eval/reread_captions.py`): every group's option captions read again; keeps the model's no-change answer.
4. **Page check** (`eval/page_check_working.py`, `--changed` re-checks only fields whose definition changed).
5. **Jev** (`eval/jev_forms.py`), now with the page image (`petey/validate/jev_page.py`).

Also: groups are always category / multi_category (071f954); X boxes on text widgets are groupable options (fd5171d); `eval/split_yes_no.py` turns a YES / NO pair printed over one widget into two path-less boxes read from the page (8bb840d, memory `feedback-page-over-metadata`).

### Grids

- **Rule** (docs/NAMING.md "Grids"): one wording per column, one iteration number per row (or the transpose). Letters that change page to page become numbers; letters the form refers to stay. Separate tables get prefixes. A totals row has no number.
- `eval/grid_naming.py`: finds tables by layout, reports cells off the pattern, `--fix [--apply]`.
- `.claude/skills/grid-validation/SKILL.md`: the judgment the code can't make, with the day's precedents.
- **Review page "check grid"** (9ff7ca6, 66ede90, 3b6369b):
  - tables that pass the code check are accepted without a model call (the other session's work, swept into 252723e);
  - otherwise Opus applies the skill's rules; cells are auto-accepted only when the model confirmed them (`confirmed`) or the person applied its fix.

### Decision models against the page check

`eval/jev_page_check.py --text --provider jev | openai | liquid | dapi:<model>` (`petey/validate/decisions_page.py`). 19 validated forms, 240 known name errors, each flagging the page check's number of fields (234):

| | known errors caught | cost per page |
|---|---|---|
| Opus page check | 209 | about 7 cents |
| Jev (with image) | 122 | 0.26 cents |
| OpenAI Decisions, gpt-6-luna (with image) | 115 | 0.50 cents |
| Liquid d1 direct (with image) | 109 | 0.64 cents |
| random | about 10 | |

None replaces Opus. The three cheap models mostly catch the same errors. On the 82 queue forms, Opus and Jev together catch 76% of Andrew's corrections at 5.1% of fields flagged; Opus alone 56%, Jev alone 33%. Keep Opus as the screen and Jev as the cheap second opinion.

Service notes:

- **OpenAI:** `POST /v1/decisions`, predicate questions, images inline as base64.
- **Liquid direct:** images go as a top-level `images` list of data URLs; `assets` is ignored.
- **decisions-api.dev:** text only (images silently dropped), 32 KiB per request, 1 to 8 questions.
- Keys are all in the local `.env`.

### Flat-form structure for pennies

Measured on validated forms; 104 non-IRS forms (one copy per form) unless noted. IRS forms are the worst case: their captions are line numbers.

| step | method | result | cost per page |
|---|---|---|---|
| where boxes could be | finder (code) | covers 87% of field boxes | free |
| is it a field (`eval/jev_is_field.py`) | Jev, page with widgets stripped | AUC 0.88 vs the Sonnet classifier 0.79; at 0.6 keeps 96% of real / 34% of false (classifier 95% / 36%) | 0.16 cents |
| kind (`eval/cheap_kinds.py`) | Jev picks from 11 kinds | 68% right (classifier 63%, word rule 54%); trust its date / money / phone / email / signature answers (83-99% precise) | about 0.15 cents batched |
| groups (`eval/cheap_groups.py`) | code (Yes / No pairs, rows) + Jev "same question?" over 0.7 | 81% of groups rebuilt exactly, 90% of yes / no pairs, 63% of groups of 3+ | 0.07 cents |
| names (`eval/cheap_names.py`) | caption candidates from page text, Jev picks one, code slugs it | 18% same words, 31% right words without the section, 11% close, 27% wrong, 13% none | 0.1 cents |
| missed blanks (`eval/band_blanks.py`) | open space under a printed line | recovers 26% of finder misses; 22% of its boxes real (30% after Jev) | free |

- **Names:** section headings, junk filters, line numbers, bilingual halves and context on clashing names each moved them a point or two. The validated names choose context by judgment; about 60% usable is the text-only ceiling.
- **Missed blanks:** the one part that needs real judgment.
- The kinds run cost 7x what it should have (fields with one caption were sent one request each); batch them if kinds become a step.

### Finder minor version: radio circles

- **What:** `step2flat-3.1` (615b288). `petey/synth/finder_addons.py` adds radio circles drawn as Bezier curves on top of the cached finder output: stroked paths of 4-8 curves, checkbox-sized; not filled letter outlines, not rings with a dark dot.
- **Results:** 132 validated forms: 372 of 375 circles on a real field; 362 of the 678 option boxes the finder missed recovered (CMS-855A 282, 855I 52, OSHA 301 11).
- **Ids:** added boxes are numbered after the finder's, so class maps and Add / remove dismissals keep pointing at the same boxes. Add / remove treats them as options.
- **Rule:** an additive rule is a minor version in `finder_addons`. Any edit inside `step2flat/` re-keys every cached finder run (520) and class map (546) and blanks Add / remove's finder suggestions until reruns. A full `FINDER_LABEL` bump is only for rules that change or drop the finder's boxes.

## Gotchas

- **Shared tree.** Another session edits this tree. `git commit -a` once swept its uncommitted grid-check work into 252723e (pushed, history left as is). Stage only your own files.
- **Saved forms write straight to the blueprint.** When Andrew has saved a form, no working copy is open, and an `--apply` or `field_add.apply` writes to the saved blueprint (it happened with the medical packet's 57 removals). Check `draft.meta(bid)` first.
- **Page-check records after a save.** Records are filed under the working-copy path's hash, so after a save `page_check.record_path(p, bp)` names a different stem and `page_check_working.earlier_verdicts` finds none. Look up by `p.stem + "__*"` instead. Not fixed yet.
- **Finder output is cached per version.** Tools that read old caches directly need the old version string.
- **Overlays** for Andrew go in `runs/overlays/` (gitignored); editor links to the scratchpad don't open.
